# renderbyte

Render CSV/TSV byte tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/renderbyte/

## Install / run

```bash
git clone https://github.com/theworker02/renderbyte.git
cd renderbyte
node src/cli.js
node --test
```
